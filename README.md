# Zapis wersji raportów PSE

Gałąź zapisywana automatycznie przez workflow „Zapis PSE” (skrypt `zapisz.py` na gałęzi main).
Każdy wiersz CSV to wersja wiersza raportu PSE z czasem publikacji PSE (`publication_ts_utc`) i czasem odczytu (`odczyt_utc`).

- `zapis/poze-redoze/` – ograniczenia OZE ze względów bilansowych i sieciowych
- `zapis/price-fcst/` – prognoza CEN
